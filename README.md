# Orbit Launcher

[Launcher fuer Windows herunterladen](https://github.com/ERIKSON2006/orbit-launcher/releases/download/launcher/Orbit-Launcher-Windows.zip)

1. ZIP herunterladen und entpacken.
2. `Orbit.exe` starten.
3. Spielversion auswaehlen, auf **Installieren** und danach auf **Spielen** klicken.

Der Launcher laedt seine Bibliothek und die Spiele automatisch aus diesem Release. Eine GitHub-Anmeldung ist fuer Spieler nicht erforderlich. Bereits installierte Spiele lassen sich auch offline starten.

## The Entity

Verfuegbare Versionen: **1.5.3**, **1.3.2**, **1.3.1**, **0.2.1** und **0.1.0**. Die Archivversionen koennen parallel installiert werden.

[Alle Downloads](https://github.com/ERIKSON2006/orbit-launcher/releases/tag/launcher)

Die Installation prueft Dateigroesse und SHA-256. Launcher-Updates sind in den Einstellungen verfuegbar.
