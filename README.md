# Orbit Launcher

[Launcher fuer Windows herunterladen](https://github.com/ERIKSON2006/orbit-launcher/releases/download/launcher/Orbit-Launcher-Windows.zip)

ZIP entpacken und **Orbit.exe** starten. Keine GitHub-Anmeldung erforderlich.

## Version 1.4.0

Optimierte Bibliothek mit wiederverwendeten Spielbildern, weniger UI-Neuaufbau, schnellerer Versionsgruppierung und Hintergrundverarbeitung fuer Pruefsummen und ZIP-Installationen. Katalogabfragen nutzen HTTP 304, wenn der Server dies unterstuetzt. Die Oberflaeche bleibt bei Dateiarbeiten bedienbar.

**Update:** Einstellungen oeffnen, **Nach Launcher-Update suchen**, danach neu starten. Die vorhandene EXE kann dieses Update laden.

Das eigene Orbit-Symbol bleibt erhalten. Wer noch eine alte EXE mit Godot-Symbol verwendet, laedt die aktuelle ZIP einmal neu herunter und ersetzt die alte EXE.

## The Entity

Die Versionen **1.5.3**, **1.3.2**, **1.3.1**, **0.2.1** und **0.1.0** bleiben ueber die geschlossene Versionsauswahl verfuegbar und parallel installierbar. Neue Spiele erscheinen durch Aktualisieren des Online-Katalogs. Bereits installierte Spiele lassen sich auch offline starten.
