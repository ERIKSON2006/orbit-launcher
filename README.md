# Orbit Launcher

[Launcher fuer Windows herunterladen](https://github.com/ERIKSON2006/orbit-launcher/releases/download/launcher/Orbit-Launcher-Windows.zip)

1. ZIP herunterladen und entpacken.
2. `Orbit.exe` starten.
3. Spielversion auswaehlen, **Installieren** und danach **Spielen** druecken.

Keine GitHub-Anmeldung erforderlich. Die Bibliothek und die Spiele werden automatisch aus dem oeffentlichen Release geladen. Installierte Spiele lassen sich auch offline starten.

## Version 1.1.0

Dunkelblaue Bibliothek mit Favoriten, Suche und Filtern; Download-Warteschlange und Verlauf; Einstellungen fuer Darstellung, Katalogpruefung, automatische Spielupdates und Offline-Modus. Installierte Spiele lassen sich pruefen, reparieren und deinstallieren. Spielzeit und zuletzt gespielte Titel werden lokal erfasst.

**Update von Version 1.0.0:** Im bisherigen Online-Launcher zuerst **Aktualisieren**, danach **Einstellungen > Nach Launcher-Update suchen**. Anschliessend den Launcher neu starten.

Neue Spiele erscheinen ueber den Katalog. Dafuer muss keine neue Launcher-EXE installiert werden.

## The Entity

Versionen: **1.5.3**, **1.3.2**, **1.3.1**, **0.2.1** und **0.1.0**. Archivversionen koennen parallel installiert werden.
