# Orbit Launcher

[Launcher fuer Windows herunterladen](https://github.com/ERIKSON2006/orbit-launcher/releases/download/launcher/Orbit-Launcher-Windows.zip)

ZIP entpacken und **Orbit.exe** starten. Keine GitHub-Anmeldung erforderlich.

## Version 1.2.0

Eine kompakte, an Steam orientierte Bibliothek. Jedes Spiel erscheint einmal; aeltere Versionen liegen in einer geschlossenen Versionsauswahl neben dem Installieren-/Spielen-Knopf. Die Auswahl wird gespeichert. Favoriten, Downloads, Dateipruefung, Reparatur und Einstellungen bleiben verfuegbar.

**Update:** Bibliothek aktualisieren, Einstellungen oeffnen, **Nach Launcher-Update suchen**, danach neu starten. Eine neue EXE ist fuer dieses Oberflaechen-Update nicht noetig.

## The Entity

Im Launcher **The Entity** auswaehlen. Rechts neben **Installieren/Spielen** die Versionsliste oeffnen, falls du eine aeltere Ausgabe spielen moechtest. Verfuegbar sind **1.5.3**, **1.3.2**, **1.3.1**, **0.2.1** und **0.1.0**. Sie koennen weiterhin parallel installiert werden.

Neue Spiele erscheinen durch Aktualisieren des Online-Katalogs. Bereits installierte Spiele sind auch offline startbar.
