# Orbit Launcher

[Launcher fuer Windows herunterladen](https://github.com/ERIKSON2006/orbit-launcher/releases/download/launcher/Orbit-Launcher-Windows.zip)

ZIP entpacken und **Orbit.exe** starten. Keine GitHub-Anmeldung erforderlich.

## Automatische Updates (1.6.0)

Der Launcher prueft standardmaessig beim Start und alle fuenf Minuten auf neue Launcher-Versionen. Neue Pakete werden automatisch heruntergeladen und geprueft. Beim normalen Schliessen wird das bereitliegende Update uebernommen; beim naechsten Start ist die neue Version aktiv. Laufende Spiele werden nicht ungefragt geschlossen.

**Einmaliger Umstieg von aelteren Versionen:** Einstellungen oeffnen, **Nach Launcher-Update suchen**, danach neu starten. Ab Version 1.6.0 erfolgen weitere Pruefungen und Downloads automatisch.

Die Automatik laesst sich in den Einstellungen deaktivieren und beruecksichtigt den Offline-Modus. Fuer eine andere Godot-Engine oder ein neues eingebettetes Desktop-Symbol ist weiterhin eine neue EXE erforderlich.

## Shop und Bibliothek

Im **Shop** entdeckst und installierst du Spiele. Die **Bibliothek** zeigt nur installierte Spiele. Neue Spiele erscheinen durch Aktualisieren des Online-Katalogs.

The Entity ist in den Versionen **1.5.3**, **1.3.2**, **1.3.1**, **0.2.1** und **0.1.0** verfuegbar. Aeltere Versionen liegen in der geschlossenen Versionsauswahl und bleiben parallel installierbar. Installierte Spiele lassen sich offline starten.
